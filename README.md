# PetClean
Página informativa sobre un rastrillo removedor de pelos para alfombras y tapizados.

## Archivos
- `index.html`: estructura y contenido.
- `css/style.css`: estilos y diseño responsive.
- `img/`: imágenes del producto.

## Publicar con GitHub Pages
1. Subí el contenido de esta carpeta al directorio raíz de un repositorio público.
2. En Settings > Pages, seleccioná Deploy from a branch.
3. Elegí la rama `main` y la carpeta `/ (root)` y guardá.
